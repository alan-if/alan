# Alan Design Documentation

The sources for these documents have been moved to the Alan Docs project on
[Github](https://github.com/alan-if/alan-docs), where they are maintained as
AsciiDoc and built to HTML:

| was here                  | now                                                             |
|---------------------------|-----------------------------------------------------------------|
| `design.doc`              | [`/alan-design/design.asciidoc`](https://github.com/alan-if/alan-docs/tree/master/alan-design) |
| `rules.rtf`               | [`/alan-design/rules.asciidoc`](https://github.com/alan-if/alan-docs/tree/master/alan-design) |
| `ACTORS_IN_CONTAINERS.md` | [`/alan-design/actors-in-containers.asciidoc`](https://github.com/alan-if/alan-docs/tree/master/alan-design) |

The Alan Docs project is an effort to collect all essential documentation for
the Alan Interactive Fiction System in a canonical location.

## Not moved

`Alan Transitivity.mm` is a FreeMind mind map used while working out the
transitivity rules. There are no mind maps in the Alan Docs project, so it is
kept here as a working note.

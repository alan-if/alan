# Alan Manual, Conversion Guide and Author's Guide

The sources for these documents have been moved to the Alan Docs project on
[Github](https://github.com/alan-if/alan-docs), where they are maintained as
AsciiDoc and built to HTML and PDF:

| was here          | now                                                    |
|-------------------|--------------------------------------------------------|
| `manual.odt`      | [`/manual/`](https://github.com/alan-if/alan-docs/tree/master/manual) |
| `conversion.odt`  | [`/conversion/`](https://github.com/alan-if/alan-docs/tree/master/conversion) |
| `writing.odt`     | [`/writing/`](https://github.com/alan-if/alan-docs/tree/master/writing) |

The Alan Docs project is an effort to collect all essential documentation for
the Alan Interactive Fiction System in a canonical location. The versions that
used to live here were last updated in 2019 and described 3.0beta5, while the
Alan Docs versions are newer. Nothing in the Alan build ever referred to them.

## Not moved

`references.odt` is a bibliography of adventure game articles and books,
written in 2005. It has no counterpart in the Alan Docs project, so it is kept
here until someone decides whether it is worth porting or has simply been
overtaken by the web.
